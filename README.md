# BMS Desktop Offline

Proyek aplikasi desktop Windows BMS yang terpisah dari BMS Mobile/Web.

## Fondasi
- .NET 8
- Windows Forms
- PostgreSQL lokal/LAN
- Internet tidak diperlukan untuk operasional lokal
- Database pusat dapat digunakan beberapa PC melalui jaringan lokal

## Status
Fondasi aplikasi Windows sudah dibuat. Tahap berikutnya: Login, role, Administrator, dan skema database awal.

## Prinsip
Source BMS Mobile/Web tidak diubah oleh proyek ini. Aturan bisnis BMS akan dipindahkan bertahap dan diverifikasi per modul.
