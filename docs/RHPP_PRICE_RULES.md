# Aturan Harga RHPP

- Harga performa RHPP mengikuti kontrak yang aktif pada cycle, bukan harga beli Logistik.
- Harga BW dicari dari rentang BW pada kontrak.
- Tambah Daging: nilai performa RHPP menggunakan harga BW kontrak, sedangkan hutang/biaya supplier memakai harga beli aktual.
- Extra pakan/sapronak dan biaya perusahaan di luar kontrak dikurangkan setelah RHPP kontrak sesuai aturan bisnis.
- Jika harga kontrak atau data sumber belum tersedia, tampilkan tidak tersedia (`-`) dan jangan mengganti dengan data palsu/angka nol sebagai seolah-olah data nyata.
