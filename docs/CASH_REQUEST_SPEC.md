# Form Pengajuan Kas

Dokumen administratif Finance, akses ADMIN dan KEUANGAN.

Struktur final: satu Form Pengajuan Kas memiliki banyak kelompok; satu kelompok memiliki banyak rincian.

Jenis kelompok: Kandang, BOP Umum, BOP Kantor, Proyek/Lainnya. Untuk kelompok Kandang, kandang dipilih satu kali pada header kelompok. Rincian berisi Uraian, Jumlah, Keterangan.

Dokumen ini berdiri sendiri. Pembuatan/persetujuan Form Pengajuan Kas tidak boleh otomatis membuat BOP Produksi, BOP Umum, BOP Kantor, Kasbon, Arus Kas, Hutang, RHPP, Laba/Rugi, atau transaksi realisasi lain.
