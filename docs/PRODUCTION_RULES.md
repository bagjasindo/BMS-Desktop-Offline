# Produksi/PPL

- Chick-In mengaktifkan cycle/kandang.
- DOC diterima adalah populasi awal; Mati Box/DOA dicatat terpisah.
- Recording Day 1 dimulai H+1.
- Pakan kontrak dan pakan EXTRA dibedakan.
- Liga/pekerjaan ABK dicatat per cycle dan tidak dicampur dengan Perawatan/Renovasi Kandang.
- Extra sapronak dicatat terpisah agar dapat dikurangkan setelah perhitungan RHPP kontrak sesuai aturan bisnis.
- Cycle CLOSED tidak boleh menerima perubahan data produksi.
- FCR/IP hanya dihitung dari data nyata; data tidak tersedia tidak boleh dipalsukan menjadi transaksi.
