# Matriks Hak Akses Desktop

- ADMIN: kontrol sistem, akun, master, seluruh modul operasional, audit, backup/restore.
- PRODUKSI/PPL: recording dan RHPP sesuai assignment kandang.
- LOGISTIK: pembelian/penerimaan/stok sesuai assignment kandang.
- MARKETING: customer dan panen sesuai lingkup kerja.
- KEUANGAN: pembayaran, piutang/hutang, BOP, pengajuan kas, laporan global.
- OWNER: dashboard/laporan dan restore; tidak menginput transaksi operasional.
- PELANGGAN: hanya transaksi miliknya sendiri pada tahap portal terkait.

Pembatasan UI bukan satu-satunya keamanan. Service wajib memeriksa role/scope sebelum operasi sensitif.
